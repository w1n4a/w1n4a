## 📦 Главный проект: CTkPlus

<div style="background: #161b22; border: 1px solid #30363d; border-radius: 8px; padding: 20px; margin-bottom: 30px;">
  <p style="font-size: 1.1em; line-height: 1.7; color: #c9d1d9; margin-top: 0;">
    <b>CTkPlus</b> — это независимая библиотека интерфейса для Python, которая дополняет CustomTkinter готовыми сложными виджетами. Вместо того чтобы каждый раз писать с нуля базовые элементы приложений, библиотека предоставляет готовую модульную базу компонентов, заточенных под реальные задачи разработчиков десктопного софта.
  </p>
  
  <h3 style="color: #58a6ff; margin-top: 20px; margin-bottom: 10px;">Реализованные компоненты:</h3>
  <ul style="color: #c9d1d9; line-height: 1.6; padding-left: 20px;">
    <li><b>CTkEntryButton:</b> Поле ввода, в которое сразу встроена кнопка действия (например, для отправки текста или поиска). Избавляет от необходимости вручную выстраивать сетку и подгонять пиксели.</li>
    <li><b>CTkSpinBox:</b> Элемент для удобной работы с числовыми диапазонами и шагами, которого критически не хватает в стандартном наборе библиотек.</li>
    <li><b>Модифицированные фреймы:</b> Контейнеры с переработанной внутренней логикой управления дочерними элементами и фиксированной высотой/шириной без багов адаптивности.</li>
    <li><b>Интерактивные элементы:</b> Виджеты со встроенной обработкой фокуса ввода и hover-эффектов наведения, работающие стабильно без написания лишних обработчиков событий в коде основного приложения.</li>
  </ul>
  
  <p style="margin-bottom: 0; margin-top: 20px; font-size: 0.95em; color: #8b949e;">
    🛠️ Библиотека находится на стадии беты, опубликована на <b>PyPI</b> и тестируется в реальных сценариях для создания чистых и отзывчивых интерфейсов программ.
  </p>
</div>
