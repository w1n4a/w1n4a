## 📦 Главный проект: CTkPlus

<div style="background: #161b22; border: 1px solid #30363d; border-radius: 8px; padding: 20px; margin-bottom: 30px;">
  <p style="font-size: 1.1em; line-height: 1.7; color: #c9d1d9; margin-top: 0;">
    <b>CTkPlus</b> — библиотека интерфейса для Python, расширяющая возможности CustomTkinter. Убирает базовые ограничения стандартных виджетов и предоставляет готовые кастомные элементы из коробки. Проект опубликован на <b>PyPI</b> и находится в стадии беты.
  </p>
  
  <h3 style="color: #58a6ff; margin-top: 20px; margin-bottom: 10px;">Ключевые фичи:</h3>
  <ul style="color: #c9d1d9; line-height: 1.6; padding-left: 20px;">
    <li><b>Модернизация фреймов:</b> Новая логика контейнеров для точного позиционирования.</li>
    <li><b>Кастомные спинбоксы:</b> Готовый элемент SpinBox для удобной работы с числами.</li>
    <li><b>Элементы ввода:</b> Поля ввода с поддержкой правильных фокусов и встроенных кнопок.</li>
    <li><b>Интерфейс:</b> Компоненты со стабильной сменой состояний при наведении.</li>
  </ul>
</div>
