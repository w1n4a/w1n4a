### 📦 Spotlight Project: CTkPlus
**CTkPlus** is an extension library for **CustomTkinter (Python)** designed to eliminate UI boilerplate. Instead of building complex interface elements from scratch, CTkPlus provides clean, production-ready custom widgets that can be instantly imported into any project.

* 🚀 **Currently Released:** Beta version available on [PyPI](https://pypi.org).
* 🎨 **Ready-to-use Widgets:**
  * `CTkEntryButton` – A seamless text entry field with an integrated button, perfect for search bars.
  * `CTkSpinBox` – A robust numerical selector with adjustable steps, filling a major gap in stock CustomTkinter.
  * `CTkSelector` – An intuitive custom component for switching states or navigating layout views.
* 🔮 **Roadmap:** Active development is underway to introduce a comprehensive suite of advanced UI components.
